# Changelog

## [1.0.0] - 2026-10-16

### Added
- Initial release of ByteStackLab Icons
- 50+ file type icons using ByteStackLab Material Theme color palette
- Smart folder icons for common directories (src, components, dist, node_modules, etc.)
- Support for web (HTML, CSS, SCSS, JS, TS, Vue, Svelte)
- Support for backend languages (Python, Go, Rust, Ruby, PHP, Java, Kotlin, C, C++, C#)
- Support for data/config files (JSON, YAML, TOML, XML, CSV, ENV)
- Support for shell scripts (sh, bash, zsh, PowerShell)
- Support for docs (Markdown, MDX, PDF, TXT)
- Support for images (PNG, JPG, GIF, SVG, WebP)
- Special file name mappings (Dockerfile, .gitignore, package.json, etc.)
