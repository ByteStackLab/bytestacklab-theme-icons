## Features

- 🎨 **Perfectly matched** with ByteStackLab Material Theme colors
- 📁 **Smart folder icons** — `src`, `components`, `dist`, `node_modules`, and more
- 📄 **50+ file type icons** — JS, TS, Python, Go, Rust, Docker, and more
- ⚡ **Lightweight** — Pure SVG, no fonts needed

## Installation

1. Install from VS Code Marketplace
2. Open Command Palette → `Preferences: File Icon Theme`
3. Select **ByteStackLab Icons**

## Pairing

Best used with **[ByteStackLab Material Theme](https://marketplace.visualstudio.com/items?itemName=bytestacklab.bytestacklab-material-theme)** for a fully cohesive look.
